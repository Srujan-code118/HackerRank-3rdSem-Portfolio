# HackerRank 3rd Semester Portfolio

## About
This repository contains solutions to five algorithmic challenges completed on HackerRank as part of the 3rd Semester Portfolio Building activity. The solutions are implemented in Python 3 and focus on algorithmic problem-solving, arrays, strings and efficient data handling.

## Problems Solved

| No. | Problem | Topic | Time Complexity | Space Complexity |
|---|---|---|---|---|
| 1 | Diagonal Difference | 2D Arrays | O(N) | O(1) |
| 2 | Dynamic Array | Dynamic Arrays, XOR | O(N + Q) | O(N + Q) |
| 3 | Time Conversion | Strings, Date Formatting | O(1) | O(1) |
| 4 | Compare the Triplets | Basic Implementation | O(1) | O(1) |
| 5 | Sparse Arrays | Strings, Frequency Mapping | O(N + Q) | O(N) |

## Reflection
This activity helped me improve my algorithmic problem-solving skills through practical challenges on HackerRank. I learned to traverse matrices efficiently, manipulate dynamic sequences and use bitwise XOR to calculate sequence indices. The Time Conversion problem improved my understanding of string formatting and handling time representations. Compare the Triplets helped reinforce conditional logic and element-wise comparisons. Sparse Arrays introduced efficient frequency counting using dictionaries, which avoids repeated searching and improves performance. I also learned the importance of analyzing time and space complexity while choosing an algorithm. By organizing my solutions in a public GitHub repository, I gained experience in version control, code documentation and maintaining a programming portfolio. These exercises strengthened my programming foundation and encouraged me to write cleaner and more efficient code.
